## 🔍 About the Project

This repository presents my work on configuring **secure remote access** using [Tailscale](https://tailscale.com/), a modern, zero-config VPN solution built on top of WireGuard.

In this project, I set up a **private, encrypted VPN mesh network** that enables seamless and secure communication between distributed devices across different networks. The focus was on providing **secure access** to internal resources (servers, systems, tools) without exposing them to the public internet.

> ⚠️ This project is **configuration-based** and is shared here purely as a portfolio showcase. It is not intended for public deployment or reuse.

---

## 💡 Project Objectives

- Establish a **secure VPN mesh** using Tailscale between remote machines.
- Provide **remote access** to internal services (e.g., SSH, web servers) without opening public ports.
- Demonstrate practical knowledge of:
  - Identity-based access control (via Google/Microsoft SSO).
  - Encrypted peer-to-peer communication (WireGuard-based).
  - Firewall rules and access policies.
- Showcase a hands-on approach to **modern remote access security**.

## 🧠 My Learning Process

This project demonstrates my ability to:
- Deploy modern VPN solutions in a **secure, scalable, and efficient** manner.
- Understand and apply **zero-trust principles** to real-world access problems.
- Configure and test **identity-based access control systems**.
- Learn and apply new tools independently, even with no prior background.
- Combine **cybersecurity best practices** with practical, working configurations.

While I was unfamiliar with **advanced VPN configuration**, I actively researched, experimented, and applied best practices to:
- Install and configure Tailscale clients across devices.
- Set up **ACLs (Access Control Lists)** to enforce fine-grained access policies.
- Test and validate connectivity across network segments.
- Securely expose internal services without ever opening inbound firewall ports.

---

## 📁 Project Highlights

- **Zero-Trust Network Access**: Devices only communicate after authentication and authorization.
- **Simple Setup, Strong Security**: Tailscale simplifies VPN configuration without sacrificing encryption or control.
- **Access Control via SSO**: Users log in using corporate or personal identity providers.
- **Service Isolation**: Internal services remain shielded from the public internet while accessible over the VPN.
